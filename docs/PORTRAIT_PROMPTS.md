# ANIME//SIM — Character Portrait Prompt Sheet

Ready-to-paste prompts for an AI image tool (Midjourney, DALL-E/ChatGPT, Stable Diffusion, etc.). Generated directly from each character's actual in-game appearance data (`src/content/worlds/*/npcs.ts`), so they're guaranteed to match what the game already describes — not guessed.

**Tip for consistency across ~29 characters**: generate one character first, then use that image as a style/reference image (Midjourney `--sref`, or a reference-image upload in your tool of choice) for the rest, so they all read as the same show/art style instead of 29 unrelated pictures.

**File naming**: save each result as `<id>.png` using the ID column below, drop it in `anime-sim/public/portraits/`, done — no code changes needed beyond setting that NPC's `portraitImageUrl` field to `/portraits/<id>.png` (ask me to wire a batch in once you have files).
